# TypeScript Code Style Rules

These rules apply to all project source code in `src/**`. Do NOT apply to third-party code, vendor files, node_modules, generated files, or framework boilerplate.

Load the full rules from `~/.claude/documents/typescript-rules.md` and follow them.

## Quick Reference

- Single quotes for strings
- Tabs for indentation (4 spaces wide)
- No semicolons
- No trailing commas
- `==` instead of `===`
- Single-statement blocks without braces
- `else`/`catch` on new line
- Prefer `const` over `let`, never `var`
