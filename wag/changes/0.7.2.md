# 0.7.2 — The Architecture doc owns the tech stack

**From:** 0.7.1
**Date:** 2026-10-28

The house default stack lived in `/wag:create-nextjs`'s install commands. The Architecture
template's `Tech stack` table was all placeholders, and the scaffolder never read the
Architecture doc. It installed its own list and asked about optional layers, so what init
decided and what got installed could drift apart without anyone noticing. Now the doc states
the stack and the command follows it.

## What changed

- **The Architecture template's `Tech stack` table starts pre-filled with the house default.**
  - **Baseline rows:** Node 24 + pnpm, Next.js + TypeScript, Tailwind + shadcn/ui + lucide,
    MobX, Zod, react-hook-form, Vitest + Playwright, Vercel.
  - **Optional rows:** Database (`/wag:add-db`), Auth (`/wag:add-auth`), Theme
    (`/wag:add-theme`).

  Each row says whether it's baseline or optional. Research keeps what applies and records
  each departure with its reason. The manifest's tech-stack item now says a web app starts
  from this default.
- **`/wag:create-nextjs` reads `.wag/docs/Architecture.md`.**
  - It installs the baseline rows, applying the doc's departures (a dropped row isn't
    installed and its scaffolded code isn't written; a swapped row installs the
    replacement).
  - It installs exactly the optional layers the doc lists, without asking.
  - With no Architecture doc (a standalone run) it uses the house default and asks about
    layers, as before.
- **Init** points research at the pre-filled table, and Phase C no longer passes the stack
  along by hand; the scaffolder reads it from the doc.

## Reconcile a 0.7.1 project

- **Detect:** `wag_version` < 0.7.2.
- **Reconcile:** nothing on disk. An existing Architecture doc already states its stack. A
  project that hasn't scaffolded yet should make sure its `Tech stack` section lists the
  optional layers it wants, since `/wag:create-nextjs` now installs only those.
- **Verify:** `/wag:create-nextjs` reports which layers and departures it took from the doc.
