# 0.3.0 — TRI arrives, corpuses go

**From:** 0.2.0
**Date:** 2026-06-10

The cycle gains its fifth phase: `ADR → [DEV → RVW]* → TRI`. Issues are tackled head-on at the end of each round (or immediately when one blocks); every resolution lands **local** (the project), **global** (the WAG system — mechanically embedded), or **both**. The corpuses are removed: no learning promotion, no resolved-snag archive.

## What changed

- **`/wag:tri` introduced** (synonym `/wag:triage`) — the TRI phase. Mid-cycle excursion when a snag blocks (snags only); cycle-end drain after merge (snags + review snag-candidates + stash triage).
- **`/wag:review` renamed to `/wag:rvw`** — `/wag:review` remains as an alias stub.
- **Snag resolution moved into TRI.** Commands (`/wag:docs`, `/wag:adr`, `/wag:dev`, `/wag:rvw`) still halt on any open snag, but now route to `/wag:tri` (driven inline) instead of owning the protocol themselves.
- **Resolution protocol Step 4 is now Disposition** (local / global / both) — replaces Promote. A global rule embeds mechanically into a wag template or command *in-session*; there is no pending state and no learning file.
- **Closed snags are deleted, not archived.** `git rm` at closure; the record is the doc changelog line + git history. `.wag/snags/_resolved/` is no longer written.
- **The learnings corpus is frozen.** Nothing writes to `~/.claude/wag/learnings/` anymore. Existing entries are drained via a one-time migration TRI (embed mechanically / fold into docs / delete). Corpus reads in `/wag:adr`, `/wag:dev`, `/wag:rvw` remain until the drain empties the directory, then no-op.
- Snag template: `Promotion candidate` section replaced by `Disposition`; status `resolved` removed (resolution deletes the file).

## Reconcile a 0.2.0 project

No on-disk change is forced — the cycle change is command-level.

- **Detect:** `wag_version` < 0.3.0.
- **Reconcile (optional):** `.wag/snags/_resolved/` may be deleted (`git rm -r`) — resolutions live in git history. Any snag file carrying `**Status:** resolved` is a defect under the new model: it should have been deleted; delete it.
- **Verify:** `.wag/state.json` carries `wag_version` 0.3.0; `.wag/snags/` contains only genuinely open snags (each one blocks all work until TRI resolves it).
