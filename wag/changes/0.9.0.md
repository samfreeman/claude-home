# 0.9.0 — The POC renders its own docs, from generated copies

**From:** 0.8.1
**Date:** 2026-10-29

Built first for VÖROOM, by voice. Project Plan & Status showed the PRD and Architecture by
framing `poc/docs/PRD.html` and `Architecture.html`, polished renders that had to be rebuilt
by hand on every change and drifted from the markdown. The page now renders the markdown
itself. This changes what's in `poc/docs/`, hence the minor version.

## What changed

- **Generated docs copies** (`wag/workflows/poc.md`, the docs-copies rule):
  `.wag/poc/docs/PRD.js` and `Architecture.js` replace `PRD.html` and `Architecture.html`.
  Each sets `window.POC_DOCS.prd` (or `.architecture`) to its source path, file name,
  generated date and full markdown, under a "GENERATED, DO NOT EDIT" header. A `.js` file
  because a page opened from disk can't fetch a `.md`, but it can load a script.
  `.wag/docs/PRD.md` and `Architecture.md` stay the sources of truth.
- **Regenerated with the source:** any step that writes `PRD.md` or `Architecture.md` writes
  its copy in the same step (Steps 1, 4 and 5), creating `poc/docs/` if needed. The
  workflow states the escaping (backslashes, backticks, `${`).
- **No readable sibling** for the copies: they carry no markup.
- **The starter's `pages/project-plan-status.html`** has no frames. It loads `marked@15`
  and the two copies, renders each doc in its accordion item in the POC's theme (with a
  `.doc` stylesheet), shows where each came from and when, downloads the markdown as
  `PRD.md` / `Architecture.md`, and draws `├──` / `└──` directory trees as icon trees.
- **The POC no longer uses `/wag:html-prd` or `/wag:html-architecture`.** Those commands
  are unchanged and still produce the standalone polished renders.

## Reconcile a 0.8.1 project

- **Detect:** a POC whose `pages/project-plan-status.html` has iframes, or whose `poc/docs/`
  holds `PRD.html` / `Architecture.html` rather than `PRD.js` / `Architecture.js`.
- **Reconcile:**
  1. Generate `poc/docs/PRD.js` and `Architecture.js` from `.wag/docs/`.
  2. Replace `pages/project-plan-status.html` from the starter, keeping the project's head
     (fonts, theme mapping) and look. Write `pages/project-plan-status.html.md` first, then
     decode it.
  3. Delete `poc/docs/PRD.html`, `Architecture.html` and their `.html.md` siblings.
- **Verify:** both docs render in place on Project Plan & Status, opened from disk, with the
  note line, a working Download, and any directory tree drawn as a tree.
