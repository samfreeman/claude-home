# 0.8.0 — The POC is one small file per page

**From:** 0.7.7
**Date:** 2026-10-29

Found by voice. The POC was one `index.html` holding every route, and voice can't write one
large file in a single call: a roughly 38 KB `index.html` failed repeatedly. The POC is now
a set of small pages that share a few common files. This changes the POC's markup contract,
hence the minor version.

## What changed

- **Pages come from the routes** (`wag/workflows/poc.md`, Step 5). Once the PRD's routes are
  settled, the page map follows mechanically:
  - one HTML file per route, all in `.wag/poc/pages/`: `/` is `pages/index.html`, `/x` is
    `pages/x.html`. Pages link by bare name and load the shared files with `../`. The root
    `.wag/poc/index.html` only redirects to `pages/index.html`, so the POC's address opens
    the landing page;
  - a dynamic route `/x/[id]` folds into `pages/x.html` and reads `?id=`;
  - signed-out and signed-in views of the same route share one file;
  - each page holds only its own content, under about 10 KB.

  Voice states the page map back to the user before writing pages.
- **A shared `shell.js`** draws the signed-in shell (the nav) and holds the theme toggle, the
  simulated sign-in state and the sign-in guard, `data-fill`/`data-list`/`data-record`
  rendering, the `?id=` switch (`data-if`/`data-unless`), and the nav's `aria-current`. Its
  opening comment is the markup contract, replacing the old one in `index.html`. Every page
  loads `theme.css`, `data.js` and `shell.js`.
- **The starter** (`wag/templates/poc/`) is now `pages/index.html` (landing and dashboard),
  `pages/sign-in.html`, a sample `pages/items.html` (list plus detail),
  `pages/project-plan-status.html`, the root `index.html` redirect, `shell.js`, `data.js`,
  `theme.css`, `vercel.json` and `.vercelignore`. It has no
  app-specific content; the menu is `NAV` in `shell.js`, and the app's name is in `data.js`.
  Every page is under 6.5 KB.
- **The readable-copy rule covers any file with markup**, not just `.html`: `shell.js` gets
  `shell.js.md`. A file with no markup (`data.js`, `theme.css`) needs no copy.
- **`.vercelignore`** excludes `*.js.md` as well as `*.html.md`.
- **The handoff's first PBI** ports each page to its app route (`x.html` to `/x`, `?id=` to
  `/x/[id]`) and `shell.js`'s shell to the app's layout.

## Reconcile a 0.7.7 project

- **Detect:** a POC with a single `.wag/poc/index.html` whose routes are `data-route`
  sections with `#/` links.
- **Reconcile:** split it by the page map. Each `data-route` section becomes its route's page
  in `pages/` (`#/x` links become `x.html`, and `#/x/ID` links become `x.html?id=ID`). Add the
  root redirect `index.html`. Move the shell and
  router into `shell.js` from the new starter. Write each file's readable `NAME.md` first,
  then decode it. Update `.vercelignore`.
- **Verify:** every page is under about 10 KB, every link opens its page, and sign-in carries
  across pages.
