# 0.7.6 — Voice can read every WAG file: angle brackets encoded in the Dropbox copy

**From:** 0.7.5
**Date:** 2026-10-29

Found by voice. Its Dropbox reader strips tag-like spans from **any** file, not just HTML. In
`wag/workflows/poc.md`, placeholders like `APP` written between angle brackets vanished, and
one stripped span ran across lines and a heading, so Step 5's copy list and the start of
Step 6 were gone. Voice couldn't read what Step 5 asked it to build. Not every bracket is
stripped (a TypeScript generic survived in the same session), so the exact rule is unknown;
the safe assumption is that any less-than sign can start a stripped span.

## What changed

- **The Dropbox copy of claude-home encodes angle brackets in every Markdown file.**
  `scripts/readable-copies.mjs`, run by `scripts/sync-dropbox.sh` on the exported `dev`
  tree, replaces each less-than sign with U+2039 and each greater-than sign with U+203A in
  every `.md`. It still writes the encoded `NAME.md` copies of the templates' `.html` and `.js`.
  **The repo keeps real angle brackets**, because most of them sit in code that Claude Code
  writes into projects (TypeScript generics, JSX, HTML), where removing them would break the
  output.
- **The sentences that describe the encoding now use words** (less-than, greater-than,
  U+2039, U+203A) instead of the characters themselves, in `wag/workflows/poc.md`,
  `commands/wag/poc.md`, `changes/0.7.1.md` and `changes/0.7.5.md`, so the encoding stays
  reversible.
- **Standing rule, enforced:** tracked Markdown never contains U+2039 or U+203A itself. The
  sync stops with the file's name if one does, so the problem can't creep back.
- **The workflow tells voice how to read the encoding:** in claude-home's Dropbox copy, read
  U+2039 and U+203A as less-than and greater-than, and turn them back when copying code or
  markup out.

## Reconcile a 0.7.5 project

- **Detect:** nothing in projects. This changes how claude-home reaches voice.
- **Reconcile:** none. The next sync re-encodes the Dropbox copy.
- **Verify:** voice reads `wag/workflows/poc.md` from Dropbox with Step 5's copy list and
  Step 6's deploy commands intact.
