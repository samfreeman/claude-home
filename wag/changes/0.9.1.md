# 0.9.1 — The docs page is Project Documents

**From:** 0.9.0
**Date:** 2026-10-29

From VÖROOM, by voice. The POC's standard Development page holds the PRD and the
Architecture, and nothing about plan or status, so it's renamed to say what it is.

## What changed

- **The starter page** is `wag/templates/poc/pages/project-documents.html` (was
  `project-plan-status.html`), titled **Project Documents** in its `data-page` and heading.
- **The starter's `DEV_NAV`** (`shell.js`) is
  `{ href: 'project-documents.html', label: 'Project Documents', icon: 'clipboard-list' }`.
- **`wag/workflows/poc.md` and `commands/wag/poc.md`** use the new name throughout.

The real app's in-app page from `/wag:gendocs` keeps its name; this is the POC's page only.

## Reconcile a 0.9.0 project

- **Detect:** a POC with `pages/project-plan-status.html`.
- **Reconcile:**
  1. Write `pages/project-documents.html.md` from `pages/project-plan-status.html.md`, with
     the page's `data-page` and heading changed to Project Documents. Decode it into
     `pages/project-documents.html`.
  2. Delete `pages/project-plan-status.html` and its `.html.md`.
  3. In `shell.js.md`, change the `DEV_NAV` entry to the one above, then decode `shell.js`.
- **Verify:** the Development section's link opens Project Documents, and no page links to
  `project-plan-status.html`.
