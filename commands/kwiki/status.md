# kwiki status

Show the current state of the kwiki knowledge base.

## Instructions

1. Call `wiki_status` to get unprocessed raws and node summaries.
2. Present a clean overview:
   - Number of unprocessed items in the hopper
   - Node tree with entry counts
   - Highlight any nodes with no entries or recent activity
3. If there are unprocessed raws, mention that `/kwiki/process` can handle them.
